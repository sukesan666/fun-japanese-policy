FUN JAPANESE — Privacy Policy

Last updated: 25 November 2026

English 日本語

FUN JAPANESE is a Chrome extension that translates browser tab audio and microphone speech in real time with floating bilingual subtitles and speech synthesis. It operates without any developer-owned backend server: the developer collects no personal data, runs no analytics or telemetry, and never receives your audio, transcripts, or API key.

1. Data Handled by the Extension

DataWhere it is sentWhere it is stored
Tab & microphone audioGoogle Gemini Live API (generativelanguage.googleapis.com) only while capture is runningNot stored (streamed in memory and discarded)
Transcripts & translationsShown locally in the UI; sent to 127.0.0.1 only when a local TTS engine is chosenSession memory only (unless bookmarked)
Saved phrases (Phrasebook)Nowherechrome.storage.local on your device
Your Gemini API keygenerativelanguage.googleapis.com onlychrome.storage.local on your device
Settings & glossaryNowhere (Chrome Sync only if enabled by you)chrome.storage.local / chrome.storage.sync

Model names & rates (optional)Plain static GET from sukesan666.github.io (no user identifiers sent)chrome.storage.local (short-term cache)

2. External Connections

  • Google Gemini Live API (https://generativelanguage.googleapis.com/*): Direct connection using your own API key, subject to Google's Gemini API Terms and Privacy Policy.
  • Polar (https://api.polar.sh/*): Used only when activating or validating a Pro license key (Privacy Policy).
  • Local Japanese TTS Engines (http://127.0.0.1/*, http://localhost/*): Optional local-only connection to AivisSpeech, VOICEVOX, VOICEVOX Nemo, COEIROINK v2, or SHAREVOX running on your own PC.

3. What FUN JAPANESE Does NOT Do

  • Does not collect, sell, or transfer user data to third parties.
  • Does not include analytics, telemetry, crash reporting, or advertising trackers.
  • Does not scrape or read web page content.

4. Contact

Questions or requests: GitHub Issues.

日本語（プライバシーポリシー）

FUN JAPANESE は、ブラウザのタブ音声やマイク音声をリアルタイム翻訳し、フローティング2言語字幕・音声読み上げを提供する Chrome 拡張機能です。 本拡張機能には開発者が運営する中継サーバーはありません。開発者がユーザーの音声・字幕・API キー・個人情報を収集・閲覧することは一切ありません。

2. 外部通信と権限

  • Google Gemini Live API：ユーザー自身の API キーによる直接通信（利用規約 / プライバシーポリシー）。
  • Polar：Pro ライセンスキーの認証・検証時のみ通信（プライバシーポリシー）。
  • ローカル音声合成ソフト（127.0.0.1 / localhost）：AivisSpeech・VOICEVOX・VOICEVOX Nemo・COEIROINK v2・SHAREVOX とのローカル通信のみ（外部送信なし）。

3. 行わないこと

  • ユーザーデータの収集・販売・第三者提供は一切行いません。
  • アクセス解析（Analytics）・テレメトリ・広告トラッキングは一切組み込んでいません。
  • Web ページの本文や個人情報を読み取って送信することはありません。

ご質問・ご連絡は GitHub Issues よりお願いいたします。
